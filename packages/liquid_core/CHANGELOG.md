## 0.1.0

- Initial release of `liquid_core`.
- Added core reactive primitives:
  - `Drop<T>`
  - `Flow<T>`
  - `Tub`
  - `Ripple`
  - `StreamDrop<T>`
- Added diagnostics/event APIs:
  - `LiquidDiagnostics`
  - `LiquidTimelineObserver`
- Added tests for sync state, async state, lifecycle, and diagnostics behavior.
